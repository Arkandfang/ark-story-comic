# 视觉资产与无字原画

## 资产规模由连续性风险决定

不要把一种连载流程强加给所有作品。

- 单幅、单页或低连续性作品：保留画风参考、核心主体参考和必要场景即可。
- 多页作品：增加人物／主体的关键视角、状态、比例与场景锚点。
- 连载或长期复用：建立完整视觉圣经、权威资产顺序、漂移红线和版本记录。
- 物件、动物、环境或抽象主体作品：建立与其结构相符的多角度、尺度、材质、空间或状态参考，不凭空增加人物资产。

只有在画风尚未确定、不同方案会显著影响整套生产时，才用同一内容做风格对照。对照时只改变视觉语言，不同时改变构图、角色和信息。比较原尺寸与目标观看尺寸下的叙事功能、主体识别、动作／表情可读性、文字容量和批量一致性。

## 主体识别

对需要跨格保持身份的主体，保留 3–5 个在目标观看尺寸下仍可辨的特征，例如轮廓、主色、结构、发型、服装、材质或标志物。不同主体优先通过结构、比例和动作区分，不只靠换色。

## 画风锁定

画风母版可规定线条、色彩、材质、背景密度、光影与边缘处理；动作语法可规定速度线、反应线、拟声字或其他视觉符号。每页的动态符号数量服从页面层级，不让装饰抢走主动作。

## 原画制作说明结构

```text
用途：连续叙事漫画原画。
画幅和格数：准确 N 格，说明每格大小、边界和阅读顺序。
权威主体：逐个写固定外形、比例、状态和相互关系。
连续动作：逐格说明动作、视线、物件状态和空间方向。
气泡：准确数量、所在画格、指向对象、保持完全空白。
画风：引用锁定的线条、色彩、材质、光影和背景密度。
留白：需要后期排字的屏幕、纸张、路牌或卡片保持空白。
禁止：最终对白、伪文字、水印、未要求的页码、额外主体、额外肢体、主体复制或未要求的信息装饰。
```

## 定点返修

问题局部化时只修失败区域，例如只替换背景、修正一个主体比例、补一个空白气泡或删除伪文字。返修说明必须列出冻结项；修后对冻结区域做视觉或像素差异检查，避免局部修改导致全页漂移。

## 原画目录规则

`raw/` 保存没有最终排字的权威原画。最终对白、实体文字和可选签名保存在布局数据与最终输出中。提示、修改原因、版本和废稿路径写入 `prompts.md` 或等价制作记录。
