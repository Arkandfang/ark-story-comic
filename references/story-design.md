# 故事输入、改编约束与拆页

## 先判断输入成熟度

| 输入 | 默认动作 |
|---|---|
| 一句话／主题 | 协助写成完整故事，确认后再拆页 |
| 故事大纲 | 补足用户允许补的连接段，保留既定人物、节点和结局 |
| 完整故事／脚本／文章 | 进入原文改编；先锁定不可改内容，再提取节拍，不按统一公式重写 |
| 已有逐页分镜 | 跳过故事开发，只检查遗漏、顺序、连续性和可画性 |
| 已有原画／成片 | 进入返修或审核，只改失败层 |

## 改编约束模板

```markdown
# 改编约束

- 输入类型：想法／大纲／完整故事／脚本／已有分镜
- 来源文件或原文：
- 来源版本／消息标识／内容哈希：
- 改编自由度：开放创作／允许补连接／忠实改编／逐字锁定
- 本轮交付：故事／拆页／分镜／原画／成片／审核／发布包装
- 必须保留：人物、事实、台词、事件顺序、结局、视觉物件
- 推断权限（逐项填写 allow／deny）：构图所需空间／既有动作的可见化／人物行为／因果补全／新增事实
- 旁白权限（四选一）：不可新增／可压缩原意／可改写／可新写
- 禁止新增：角色、动机、因果、反转、笑点、知识结论等
- 基调与题材：
- 画幅、平台与页数：
```

完整故事改编时，先列“必须保留”和“禁止新增”。五类推断权限必须逐项记录为 `allow` 或 `deny`，默认只有“构图所需空间”和“既有动作的可见化”为 `allow`；人物行为、因果和新增事实必须有明确授权。旁白权限四选一，默认“可压缩原意”，不能用新旁白偷偷补设定。原文没有解释的内容，不自动补成更完整、更戏剧化的版本。

## 只有输入不完整时才开发故事

以下维度按题材选用，不是统一必填项：

- 人物叙事：人物、处境、目标、阻碍、决定和结局；
- 悬疑叙事：已知、未知、线索、揭示顺序和答案；
- 日常／抒情：关系、观察、情绪变化、时间流逝和余韵；
- 喜剧：预期、偏差、升级和笑点；
- 教程／知识故事：问题、步骤、证据、结果和理解检查；
- 纪实／历史：事实、时间线、来源边界和不可虚构内容。

冲突、误解、三次升级、唯一高潮、反转、笑点和回环都不是通用要求。只有故事本身需要时才使用。

## 从故事提取节拍

先按原始顺序列出不可再压缩的视觉节拍。每个节拍记录：

```yaml
beat_id: B03
source_anchor: "文件路径＋段落 ID／行号／脚本场次／原文短摘"
what_changes: "人物得知照片中的人是谁"
change_type: information
subjects: [人物, 照片]
location_time: "渡船内／夜"
must_show: [照片, 人物辨认反应]
must_preserve: [照片内容, 识别对象]
dialogue_or_caption: "仅保留原文需要的信息"
```

可用的变化类型包括：

- `action`：动作或物件状态变化；
- `information`：人物或读者知道了新信息；
- `emotion`：情绪或态度发生变化；
- `relationship`：人物关系或权力位置变化；
- `time`：时间推进、停顿或跳切；
- `space`：人物进入、离开或重新理解空间；
- `evidence`：出现新的可见证据。

相邻节拍如果没有任何变化，可以合并；一个节拍若包含多个必须按顺序看见的变化，应拆开。

原文未交代的物件归宿、人物去向或因果，使用 `source-unresolved`；若它只是离开当前画面，使用 `exits-offscreen`。这两种状态都表示“不要补写”，不算连续性错误。

## 从节拍拆成页面

一页容纳多少节拍取决于：是否同一时间和地点、动作是否连续、信息是否必须停顿、对白容量、关键画面的视觉权重、翻页或滑页位置。不要先决定每页三格，再把故事塞进去。

页面可以承担建立、推进、观察、揭示、转场、停顿、决定、仪式、高潮或收束等任意功能。第一页不必制造事故；它只需要在目标平台上建立人物、情境、问题、气氛或视觉兴趣。结尾不必回环或反转；它只需要完成原故事的结束方式。

## 分镜密度

每格至少承担一个明确节拍或一个必要的视觉停顿。动作之外，认知、情绪、关系、时间、空间和证据的改变同样有效。

如果相邻两格只换角度而没有新的阅读价值，合并；如果一个格子同时挤入多个必须依次理解的变化，拆分。格数与版式由节拍决定，不由模板目录决定。

## 逐页分镜记录

```markdown
## P1｜页面功能｜格数

来源节拍：B01–B03
本页不可改内容：
本页主要变化：

1. 画格动作／信息／情绪：
2. 画格动作／信息／情绪：

对白／旁白：
关键人物与物件状态：
时间与空间连续性：
阅读顺序：
页尾是否需要翻页动力：是／否；原因：
气泡与实体文字数量：
```

具体画格版式在节拍拆页完成后，按 [`storyboard-selection.md`](storyboard-selection.md) 选择。

## 可懂性与忠实度冲突

若画面不补信息就可能看不懂，按顺序处理：先使用原文可追溯的旁白／实体文字；再调整镜头和画格顺序；仍不清楚时请求用户授权。不得自行新增道具、对白、人物关系或因果来解决可懂性。
