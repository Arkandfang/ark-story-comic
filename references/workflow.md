# 端到端流程与门禁

## 流程状态

```text
输入与改编边界
  → 完整内容或锁定原文
  → 顺序节拍
  → 逐页拆分
  → 分镜配方选择与实例化
  → 视觉资产
  → 按风险测试
  → 全篇无字原画
  → 排字
  → 内容／视觉／技术 QA
  → 用户要求的交付物
```

已有完整故事、分镜或原画时，从对应阶段进入，不重复前序工作。返修先识别失败层，再回到最近一个未通过的门禁。

## G0 输入与权限门禁

记录输入类型、稳定来源锚点、改编自由度、本轮交付、必须保留、分级推断权限、旁白权限和禁止新增。用户只要求分镜时不自动进入生图；用户未要求发布包装时不自动生成运营文案。

目标媒介、画幅、输出尺寸、页数范围、文件格式和大小限制优先来自用户要求或已有项目。不得把某个平台的比例、页数或文件限制写成所有漫画的默认值。进入渲染前必须把当前规格写进布局或项目记录。

## G1 内容门禁

- 只有创意时：先发展到足以拆页的内容；
- 有大纲时：仅补用户允许补的连接；
- 有完整文本时：锁定事实、顺序、结局和不可新增内容；
- 有分镜时：检查遗漏、顺序、可画性和连续性，不重写内容。

逐个核对来源节拍是否保留。原文未交代的归宿可标记 `source-unresolved`，离开当前画面可标记 `exits-offscreen`，不得为满足连续性擅自补完。冲突、误解、升级、高潮、反转、笑点或回环只在原作实际拥有时检查。

## G2 拆页与版式门禁

每页必须有来源节拍和主要变化；变化可以是动作、信息、情绪、关系、时间、空间或证据。先拆页，再定义版式需求。

先从内置 68 个 `SB` 分镜配方召回候选，再根据当前页节拍实例化准确格数、几何、面积层级和阅读顺序。硬约束失败的候选直接淘汰；召回分数不能替代结构判断。参考预览不得作为人物、画风或故事素材送入绘画。没有合适配方时使用 `custom`，不能改写内容迎合目录。

## G3 资产门禁

只建立当前作品需要的权威资产：人物、动物、物件、场景、材质、抽象主体或画风均可。单幅或低连续性作品可以使用最小参考集；连载、多角色、多场景或高一致性要求作品应增加状态、比例、空间与互动参考。

画风尚未确定且选择会影响后续批量生产时，才做同内容风格对照。已有系列优先核对 `asset-lock.md` 和最终已通过版本。废稿只保留追溯价值，不进入引用顺序。

## G4 风险测试门禁

测试规模与返工成本成正比。长篇、连载或高成本制作先选最能暴露问题的页面；单页、短篇或低成本制作可直接进入全量制作。

在原尺寸和目标观看尺寸下检查：主体漂移、阅读顺序、格数、节拍遗漏、连续性、气泡数量与文字容量。任一核心问题失败时停止扩产。

## G5 全篇门禁

逐页制作，绘画环节不得自行改写内容。生成后逐页核对：

- 来源节拍与不可改内容；
- 格数、几何层级和阅读顺序；
- 人物／主体身份、状态与比例；
- 物件、时间、空间和动作轴线连续；
- 气泡是否空白、数量和归属正确；
- 是否混入伪文字、水印或未要求的角色、事实和装饰。

## G6 排字门禁

先测量气泡主体和实体框，再设置文字安全区。矢量排字按最终字形像素审计；图像编辑模型直接排字按原画与成片差分审计。机器审计通过后仍须逐只目检和逐字核对。

## G7 交付门禁

必须具备用户要求的最终页、对应原画、可复现布局数据、目标尺寸预览、气泡／实体框审计和人工审核记录。发布文案、平台封面、合辑名或互动文案只有在用户明确要求时才属于交付物。

最后一次从最终目录重新渲染并校验，避免依赖缓存产物。

## 用户审批与自动推进

故事开发通常在内容锁定和高成本扩产前保留审批点；忠实改编则在改编边界和风险测试处审批。用户要求自动推进时，可以自审返修，但仍要保存版本和判断依据，并区分“符合约束”与“用户喜欢”。
